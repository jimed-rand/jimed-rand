### Glad to see you here!  
Good to see you! I'm James "Jim" Ed Randson. I'm now a part-time software developer and package maintainer at [OBS](https://build.opensuse.org/users/jimed-rand). In the past, I was a web developer, and I currently study at [Indonesia Open University](https://ut.ac.id), where I'm enrolled in the undergraduate Information Systems Study Program. I was also a part-time contributor at the [Pacstall Repo](https://github.com/pacstall/pacstall-programs). Now I am developing programs written in Go, like [kagami](https://github.com/jimed-rand/kagami) which helps you create custom Ubuntu ISOs, [cosmic-deb](https://github.com/jimed-rand/cosmic-deb) which helps you create the Debian/Ubuntu packages for COSMIC desktop, using the sources from [hepp3n's repo at Codeberg](https://codeberg.org/hepp3n), and [reddock](https://github.com/jimed-rand/reddock) which helps you run a Redroid container for running Android in a Docker/Podman container. I'm also building [ubuntu-vanilla-build](https://github.com/jimed-rand/ubuntu-vanilla-build), a shell-based ISO builder for creating your own Ubuntu-based distro without snapd, which I develop together with Claude. Since Kagami is fairly complex, it's now a secondary priority — I'm maturing ubuntu-vanilla-build first before I return to Kagami.
